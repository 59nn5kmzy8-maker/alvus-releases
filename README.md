# Alvus for Mac

Downloads and the update feed for Alvus. No source code lives here.

- **Install:** download the newest `Alvus-<version>-universal.dmg` from [Releases](https://github.com/59nn5kmzy8-maker/alvus-releases/releases/latest), open it, drag Alvus to Applications. The first time, macOS blocks it: System Settings → Privacy & Security → **Open Anyway**.
- **Updates:** installed copies read `latest.json` from the newest release and update themselves. Every release is signed; the app installs nothing that is not.
